# Remaining surfaces and setup follow-up

Source: https://gemini.google.com/app/09cf8496cd38905e

A second batch contained the actual unlock, execution approval, attention,
artifact and mobile navigation screens; the three implemented setup dialogs;
the accepted task list; and the owner's original Orca logo. Gemini reviewed them
in text. It explicitly reported that it had not generated a new image.

| Surface            | Review direction                                                                                                                                                              |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Unlock             | Replace the isolated login card with the requested 7:3 Orca visual and entry layout; keep infrastructure terms secondary                                                      |
| Execution approval | Explain the requested operation and its scope first; retain the exact protocol payload in expandable details; separate permission from final task acceptance                  |
| Attention          | Separate decisions from failures; show a useful summary once instead of repeating the full goal in a table and detail card                                                    |
| Artifacts          | Lead with existing references and file locations; progressively disclose MIME/digest metadata; preserve the distinction between a reference and uploaded or verified contents |
| Mobile navigation  | Give tasks and conversations priority; reduce repeated self-hosting labels; preserve focus restoration and 44px targets                                                       |
| Accepted task list | Keep business acceptance distinct from execution completion; add useful delivery/time context only when real data supports it                                                 |

Gemini recognized improvements in the three setup dialogs: assistant-oriented
copy, Cancel/primary actions, an advanced local endpoint and masked remote keys.
It proposed separating profile creation from connection management in a future
flow, and further reducing technical configuration in the ordinary path. The
first generated image itself retains the compact two-mode switch, so that change
requires a subsequent visual reference rather than an invented replacement.

Its screenshot-based estimate of 36–40px fields is not a measurement. The browser
measured desktop setup selectors at 33.5px with a 32px minimum; mobile targets
were verified at 44px. Record actual measurements when evaluating the next image.
The supplied logo must keep its own silhouette; no substitute whale was adopted.
