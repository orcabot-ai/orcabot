# Mobile navigation

The original [mobile screenshot critique](details-review.md) identified repeated self-hosted labels, infrastructure-first wording and focus/touch concerns. A [fresh Gemini review](https://gemini.google.com/app/819c9d7c44d7e256) received the actual mobile screenshot and the personal-home reference, then generated the [light/dark mobile comparison](mobile-gemini.jpg).

The implementation follows its personal-assistant hierarchy: Orcabot, clear close control, a prominent new conversation action, Home/Tasks/Projects/Routines, real dated threads and secondary attention/settings. The supplied original Orca is retained instead of the image's substitute symbol. Invented thread titles, duplicated dates and physical-phone perspective are not application UI.

The drawer is wider while retaining a clickable outside area, uses 14px navigation text and 44px controls, and respects the bottom safe area. Its entrance moves horizontally; the inherited centered-modal vertical entrance had briefly translated the full-height footer below the viewport. The focused short-screen check now verifies the appropriate drawer behavior, alongside the existing focus trap, Escape/route dismissal, focus return and inert background.

Actual 390×844 light/dark and 320×600 dark captures are retained. Independent reviews inspected the layout and the README's new personal-assistant framing. Final browser and repository check results are recorded in the manifest; the marketing-specific Taste findings remain explicitly open in [the applicability report](taste-check.md).
