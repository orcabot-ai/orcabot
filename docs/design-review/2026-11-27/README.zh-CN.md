# 鲸主题场景入口

[English](README.md) · 简体中文

本轮按用户要求，把巨大的品牌 Logo 改成真正生成的海天与鲸主题图片，再围绕图片
实现 HTML 页面。原版 Orca 保留为独立的32px小标识。轻微光流呼应个人 Agent
感知并承接工作的理念，没有虚构任务、活跃度或界面。

[打开预览](http://127.0.0.1:4320/welcome) · [生成来源与完整提示词](whale-prompt.md)

这是一张生成的摄影风格作品，不是实际野生动物摄影或科学图示，图内没有文字或
画死的控件。WebP约44KB/100KB，JPEG回退约356KB。完整提示词保留在分发资源的
metadata/sidecar中，原图和来源保存在这里；没有使用图片 API 凭证。

## 保留的行为

桌面7:3比例、密钥校验、原目标URL返回、已认证后的打开操作、中英文和session偏好
均保留。手机先显示入口，再显示方形场景以保留鲸的完整轮廓；窄而高的桌面窗口也
限制裁切。粒子与底图分离，暂停、减少动效和后台切换时，静态图片始终保留。
代码不再通过采样 Logo 绘制巨大粒子轮廓。

图片在客户端入口出现后以高优先级主动加载，没有给其他工作台路由增加全局预加载，
初始 HTML shell 里也没有该图片。不宣称 LCP 跑分或真机认证。
