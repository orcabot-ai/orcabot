按所有者确认：桌面左侧视觉 70%、右侧登录 30%，页面不纵向滚动；背景更深，前景有流动，并更贴合 Orcabot。原创矢量曲面、四条流线、轻量连接场与对话／上下文／交付装饰节点替换此前海洋图片。它们不表示真实任务状态，不引入外部图片或新依赖。

## 功能验证

完整 E2E 使用隔离夹具，通过真实 HTTP 登录路径验证 1440／964 桌面和 390／320 手机、中英文、深浅色、偏好保存、按钮对比度、触摸尺寸、无页面溢出、减少动态效果、错误密钥恢复与登录后回到原任务。另有 844×390、320×480 登录状态；极矮屏幕仅允许表单内部滚动。截图只含一次性测试数据，没有真实凭证，也没有调用模型供应商。

[current-entry.jpg](current-entry.jpg) 是实际 1031×902 桌面预览。[captures](captures/) 包含已登录、待登录、错误与减少动效状态。输入区与按钮保持静止。

## 动效证据边界

Canvas 约 30fps、DPR 最大 1.5；离屏或标签页隐藏时暂停，减少动态效果时移除。四条路径共有 74 个粒子，中心连接场有 24 个轻量节点。工具不能拖动 JavaScript RAF 时间轴，报告中的 0ms 不代表性能结果，因此另用现有 E2E 采集六秒真实时间连续帧与实际时间戳，以及相隔六秒的减少动效帧。采样只能证明观察到的行为，不代表所有设备上的性能。

## 独立审阅

Impeccable 独立审阅认可布局与响应式适配，要求修复原有错误密钥提示。现在明确提示核对启动密钥并重试，其他位置保留会话过期语义。E2E 断言准确文案和密码遮罩，再使用夹具密钥完成重试。修复项复核为 **ship**，独立代码审阅为 **approve**。动效审阅对六秒桌面样本给出 **ship**：74 帧正常动效、右侧逐像素保持不变，两张减少动效截图完全一致；不代表所有设备上的性能保证。`pnpm check` 通过（154 项通过、22 项平台跳过、零失败），完整 `pnpm e2e` 与格式检查通过。见[正常动效](motion/normal.jpg)与[减少动效](motion/reduced.jpg)采样拼图，以及同目录测量摘要。

设计规范见 [apps/web/DESIGN.md](../../../../apps/web/DESIGN.md)，开发工具 sidecar 保持忽略。按 Modern Web Guidance 的 “Connect Labels Programmatically” 规则，密钥字段提供可见 label、匹配的输入 ID 与关联错误说明。
