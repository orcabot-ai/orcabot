## 绘制与动效

原创路径定义鲸体和鳍，裁切的曲线构成曲面网格。固定数量的点与流线在最多
30fps、像素比最高 1.5 的 Canvas 中绘制。指针只轻微推动附近粒子。画面不假装
展示实时 Agent 活动。

暂停或减少动态时保留完整静态构图。页面隐藏或场景离屏后停止循环，恢复时从
先前的模拟时刻继续。content-visibility 事件直接监听对应容器；不支持该事件时
使用 IntersectionObserver。卸载时清理帧、监听器与观察器。Canvas 2D 不可用时
保留原创 SVG 轮廓，品牌文字和控件仍是 HTML。
