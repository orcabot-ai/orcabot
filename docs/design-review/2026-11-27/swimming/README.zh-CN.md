# 游动的彩色粒子鲸

[English](README.md) · 简体中文

所有者指出上一版像单色潜艇，并明确要求移除暂停按钮。这次用薄荷绿、水蓝、
紫罗兰、珠光与少量珊瑚色光点构成弯曲的鲸体。透明浅色替代实心外壳，四条
曲线替代均匀经纬网；32px 原版品牌标识仍然独立。

[动态入口](http://127.0.0.1:4320/welcome) · [源码](../../../../apps/web/src/OrcaScene.tsx)

## 游动方式

身体弯曲从肩部传递到尾部，尾部摆幅更大，胸鳍随节奏舒展，彩色水流从鲸身
后方经过。点数量与绘制量固定，循环限制为最多 30fps、像素比最多 1.5；这是
实现上限，不是性能测试分数。隐藏或离屏时停止绘制，减少动态时保留完整静态
构图。按要求不显示暂停按钮，不宣称符合全部 WCAG 要求。Canvas 不可用时
仍有代码绘制的 SVG 静态回退。
