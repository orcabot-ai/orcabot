# 产品方向

[English](../en/product-direction.md) · 简体中文

## 核心定位

Orcabot 围绕用户要完成的事情组织：感知信号、持续助手体验、任务看板、明确的状态迁移，以及后续的 A2UI。多 Agent 协作属于底层能力，不要求用户管理团队层级。

## 上下文与状态

任务拥有目标、验收条件、Thread、决策和交付物；执行尝试保留独立身份。每次调用选择有来源、有限长度的上下文，不把全部聊天当作可信指令。模型请求提交、审核、返工等动作，服务端检查权限、版本和证据后记录事实。

## 规划边界

Grokbot 是体验参考，不表示已有某厂商集成。A2UI 的协议版本、渲染器、感知来源和自动唤醒规则尚未实现。结构化界面应复用同一任务与授权协议，不执行模型提供的任意 HTML/JavaScript。
