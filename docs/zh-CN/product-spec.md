# 产品需求

[English](../en/product-spec.md) · 简体中文

## 已实现能力

跨机器、跨云的 Agent 工作台，底层使用 OctoRuntime。支持执行节点和 Agent 配置、模型与推理强度、工作目录、MCP、持久化对话、事件流、人工交互、取消和原执行恢复。前端使用 React、Tailwind 和 TanStack，支持英文、简体中文及深浅主题。

## 业务交付

业务任务有目标和验收条件，绑定 Agent 与版本化流程；显式认领、执行、提交证据，再由操作者通过或退回。运行结束不等于业务验收。SQLite 是持久事实来源，远程执行通过认证桥接完成，不同步数据库。

## 当前边界

共享密钥代表同一个可信操作者，没有独立用户或审核者身份。自动规划、一般依赖图、外部消息连接器、自动验收和 A2UI 尚未实现。工作目录必须提前存在，模型供应商凭证需要单独准备。

## 启动与体验

worker 自动准备本地执行依赖；Web 客户端独立连接 worker。普通使用不需要手动操作 Runtime。英文是默认界面与文档语言，中文选择保存在浏览器标签页会话中。
