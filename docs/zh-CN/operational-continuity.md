# 运行连续性

[English](../en/operational-continuity.md) · 简体中文

## 恢复原则

控制端重启将未观察到终态的执行标记为 unknown。使用原 Kernel/Run 身份、游标和保存的 checkpoint 恢复观察；不重新提交业务提示。Kernel 实例变化、历史过期或身份缺失时保留 unknown，交由调查。

## 人工注意力

待处理入口分别展示交互请求、失败和待业务验收。调查备注确认某个事件 revision，不改写 Runtime 结果；新事件会使旧确认失效。取消受理不等于执行已经结束。

## 产物

产物是操作者提交的未验证引用，不自动读取外部 URL 或本地文件。SQLite 保存历史、复原身份和事件，数据目录包含凭证，需要保护和一致性备份。关闭浏览器不会终止工作。

## 实现边界

共享密钥没有独立身份隔离；当前没有自动“修复”未知执行的替换策略。未知状态阻止新一轮，避免重复副作用。
