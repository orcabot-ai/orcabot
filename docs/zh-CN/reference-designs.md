# 设计参考

[English](../en/reference-designs.md) · 简体中文

## Vercel Board

参考共享频道、Thread、显式任务、租约和结构化结果的协调思想。需要把 ownership、事件与授权说清楚，而不是通过读取聊天推断状态。不要为了协调复制一套执行引擎。

## OpenBot

参考长期助手、持续对话、人工审批和一致的交互模型。Orcabot 是服务端 Web 拓扑，不直接照搬桌面设备、浏览器或沙箱的信任边界。

## 同步保持轻量

每个 worker 自己保存数据和执行身份，远程使用认证 API 桥接。避免多机同步可变 SQLite 或把共享信箱当作可靠调度器。先实现一条可验收的交付闭环，再扩展激活与连接器。

## 当前与规划

参考文档属于设计研究。已有的 worker/web 拆分、P1 人工验收见专项文档；未实现的自动计划、跨云协调和 A2UI 不因参考项目存在就视为已经提供。
