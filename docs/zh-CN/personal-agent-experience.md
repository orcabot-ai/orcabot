# 为你处理事情的个人助手

[English](../en/personal-agent-experience.md) · 简体中文

个人首页采用实际生成的 Gemini 图稿作为参考；登录入口采用单屏 7:3 结构，搭配原创抽象几何与真实服务密钥表单。首页沿用原有请求受理路径，展示真实任务、待处理事项与对话记录。其余核心页面继续遵循同一套有记录的审阅流程。

Orcabot 应该像一个可以交付事情的助手。第一屏帮助你委托任务、了解进展、处理需要你决定的事。任务看板与执行配置服务于这条主线。

## 主要界面

| 界面     | 用户的问题                         | 应呈现的内容与操作                                             |
| -------- | ---------------------------------- | -------------------------------------------------------------- |
| 首页     | 接下来交给助手什么？需要关注什么？ | 直接输入请求，展示真实记录中的进行中事项、待决策事项与最近交付 |
| 任务看板 | 我的事情推进到哪里了？             | 目标、项目自定义阶段、执行尝试、验收标准与当前允许的操作       |
| 工作线程 | 发生了什么？上下文在哪里？         | 原始对话、执行输出、问题、决策与交付引用                       |
| 例行任务 | 哪些事情需要重复处理？             | 有边界的指令、计划与预算、暂停/恢复，以及回到原线程的结果      |
| 设置     | 助手在哪里、以什么方式工作？       | 连接与执行配置，在需要时展开技术细节                           |

执行配置不是产品的主角。把事情交给 Orca，不应要求用户先理解运行时安装，或者编排一组 Agent。现有本地托管启动负责准备执行环境；供应商身份认证仍可能需要用户完成。

## 状态必须表达真实含义

亲切的表达仍要保留执行完成与业务完成的区别：

| 实际情况       | 用户体验                                       |
| -------------- | ---------------------------------------------- |
| 正在执行       | 展示当前任务与最近有用的活动                   |
| 需要授权或回答 | 展示具体问题、影响范围与操作后果               |
| 执行完成       | 展示可检查的结果；执行结束不会自动验收任务     |
| 提交了交付证据 | 展示正在审核的内容及其对应标准                 |
| 操作者接受证据 | 展示已接受的交付，并在线程中保留决策           |
| 尝试失败或过期 | 解释发生了什么，提供允许的下一步，并保留原尝试 |

直接对话的执行有独立的最近对话区域，执行完成不会变成业务已验收交付。首页最多汇总最近 20 条业务任务，进展与交付分别最多五行、每类待处理事项最多三行；存在较早记录时明确提示视图范围，并链接到可翻页的任务列表。有界的活动接口排除归档对话与看板所属执行，只返回标题、标识、状态和时间。

首页根据这些事实组织注意力，不替换项目工作流定义，也不绕过状态迁移约束。原始事件名、认领轮次等信息保留在可展开详情里，不应成为主要叙事。

## 视觉方向

保留原版 Orca 标志与品牌蓝，拉丁文字使用 Manrope，中文采用本地系统字体。表单基于参考 coss 的 Base UI 基础组件。登录页在桌面采用左侧视觉 70%、右侧实际登录 30% 的分栏，不产生纵向页面滚动。小尺寸原版标识与原创蓝色抽象几何独立于表单。手机使用紧凑视觉头部，登录保持在一屏内。极矮可视区域只让表单内部滚动，不隐藏字段或禁用缩放。这里不展示营销段落、任务演示或背景图片。四条前景流线与轻量连接节点表达上下文汇入、结果返回；离屏或切换标签页时暂停，减少动态效果模式下隐藏。登录表单保持静止。

标题与措辞应指向正在处理的事情。优先呈现“需要你决定”和实际任务名，减少基础设施术语。展示已有上下文与真实结果，不为填满空页面而制造活动、统计、通知或记忆。

## 首页改版验收

- 发出请求进入现有执行受理路径与原始线程。
- 待处理条目打开对应任务、审核或执行问题。
- 执行结束不能被展示为业务已验收。
- 空状态、加载与错误状态可区分。
- 中英文与深浅模式沿用现有偏好持久化行为。
- 键盘可操作，320px 下可使用。
- 实现必须与实际生成的 Gemini 图稿对照验收。
