# 品牌与工作台设计

[English](../en/brand.md) · 简体中文

采用所有者提供的虎鲸轮廓，保留原图和透明底深浅色版本。工作台的阅读底色使用暖近白与柔和深海灰，品牌蓝用于主操作、链接和焦点；选中区域使用中性底色。警告、成功和错误各有独立语义色。

## 应用布局

- 紧凑侧栏包含任务、项目、例行任务和最近的工作线程。顶栏展示当前区域、连接和外观设置。
- 集合使用行与分隔线。数量表示当前已加载的记录，不制造活跃度或使用量指标。
- 任务主栏放交付内容、审核表单和共享线程；右侧上下文栏放目标、验收标准和当前执行。小屏将上下文堆叠在内容上方。
- 首页以真实消息输入框为入口，展示进行中、待处理与已验收交付。工作区详情按需展开实际 Agent、节点和目录；普通对话完成与任务验收分开呈现。
- `/welcome` 是单屏品牌入口：桌面左侧 70% 为原版虎鲸与蓝色粒子，右侧为密钥入口或已登录后的打开按钮。手机先展示入口；动效可手动暂停、后台暂停并响应减少动效偏好，原始标志始终保留为静态回退。
- 控件使用统一的 6px 圆角、面板 8px、弹窗 12px。层级依靠字号、对齐和分隔线，阴影仅用于浮层。

弹窗与选择器采用 Base UI 基础组件，参考 [coss ui](https://coss.com/ui/docs) 的组合方式与密度。嵌套菜单先处理自身的 Escape，不会直接关闭父弹窗。配置弹窗宽 480px，桌面字段高 32px，高级设置逐步展开，底部提供取消与一个主要操作。其他桌面字段至少 36px，手机输入与导航触摸区域至少 44px。

拉丁文字自托管 Manrope Variable，中文回退到本地系统字体。字体轮廓更柔和，不向外部字体服务发送请求。OFL-1.1 协议随页面分发于 `/fonts/Manrope-OFL.txt`，所有者提供的 Orca 标志保持不变。手机侧栏加宽，采用14px导航文字、44px触摸区域、明确关闭入口和适应安全区域的页脚，横向入场避免整屏内容上下越界；复用弹窗焦点约束，背景不可交互，选择路由或按 Escape 后关闭，关闭时恢复键盘焦点。短暂入场遵循减少动效偏好。长配置值在内容滚动区内换行。

## 工具与验证

已安装的 Taste skill 属于开发工具，不打包进产品。采用其中的中性色、直白文案、统一控件、信息层级和克制动效原则。工作台属于操作型应用，营销页的首屏大标题、着色器场景和整屏销售段落不适用，不宣称通过营销页专用 gate；未通过的项及适用性说明见[Taste 检查报告](../design-review/2026-11-26/references/taste-check.md)。

浏览器夹具验证实际 API 与 UI，在 1440、1024、768、390 和 320px 下检查深浅色、内层溢出、弹窗／导航焦点与会话偏好。截图使用隔离示例数据，不调用付费模型。

已评估 React Bits 入场组件；当前使用原创 CSS，未引入其代码或依赖。后续导入时须固定版本、核查许可并保留声明。
