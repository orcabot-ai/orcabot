# 品牌与工作台设计

[English](../en/brand.md) · 简体中文

采用所有者提供的虎鲸轮廓，保留原图和透明底深浅色版本。工作台的阅读底色使用白色与石墨灰，品牌蓝用于主操作、链接和焦点；选中区域使用中性底色。警告、成功和错误各有独立语义色。

## 应用布局

- 紧凑侧栏包含任务、项目、例行任务和最近的工作线程。顶栏展示当前区域、连接和外观设置。
- 集合使用行与分隔线。数量表示当前已加载的记录，不制造活跃度或使用量指标。
- 任务主栏放交付内容、审核表单和共享线程；右侧上下文栏放目标、验收标准和当前执行。小屏将上下文堆叠在内容上方。
- 新对话展示实际选中的 Agent、执行节点与工作目录。配置入口执行真实操作，移除宣传式欢迎区和没有切换能力的工作区下拉外观。
- 控件使用统一的 6px 圆角、面板 8px、弹窗 12px。层级依靠字号、对齐和分隔线，阴影仅用于浮层。

弹窗限制滚动范围，保留可见标签和一个主要操作。桌面输入至少 36px，手机输入与导航触摸区域至少 44px。手机侧栏复用弹窗焦点约束，背景不可交互，选择路由或按 Escape 后关闭，关闭时恢复键盘焦点。短暂入场遵循减少动效偏好。长配置值在内容滚动区内换行。

## 工具与验证

已安装的 Taste skill 属于开发工具，不打包进产品。采用其中的中性色、直白文案、统一控件、信息层级和克制动效原则。工作台属于操作型应用，营销页的首屏大标题、着色器场景和整屏销售段落不适用，不宣称通过营销页专用 gate。

浏览器夹具验证实际 API 与 UI，在 1440、1024、768、390 和 320px 下检查深浅色、内层溢出、弹窗／导航焦点与会话偏好。截图使用隔离示例数据，不调用付费模型。
