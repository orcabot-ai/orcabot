# 品牌与动效

[English](../en/brand.md) · 简体中文

采用所有者提供的虎鲸轮廓，不重新绘制标志。保留原图，生成透明底浅色版和浅色鲸身的深色版。主色为深海蓝，动作与焦点使用亮蓝；阅读区域保持中性色，警告和错误使用独立语义色。

弹窗遵循稳定面板、明确标题、均匀边距、44px 输入和单一主要操作；小屏变为单列。允许短暂入场，减少动效时保持静态。键盘焦点留在对话框内，关闭后返回触发位置。

Taste skill 已安装在用户工具目录，属于开发工具，不打包进产品。根据工作台需求采用排版、间距、对比和轻动效规则，不把应用改成营销落地页。

React Bits 的 Animated Content / Fade Content 适合入场，Spotlight Card 可用于引导卡片；WebGL 背景、磁吸按钮与长日志逐行动画不适合持续工作的界面。本次采用原创 CSS 入场，不复制 React Bits 源码，也不增加其依赖。后续若选用组件，先固定版本、核查组件许可证并补第三方声明。
