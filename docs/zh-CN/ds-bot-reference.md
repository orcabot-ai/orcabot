# DS-Bot 参考分析

[English](../en/ds-bot-reference.md) · 简体中文

## 借鉴点

把 Bot 当作长期队友的体验可以参考：明确目标和验收、显式登记任务、协调入口、按需唤起、交接结果回传、前后台交互、分层记忆和有限 MCP 接入。

## Orcabot 的取舍

保留 OctoRuntime 执行底座、服务端 SQLite 事实来源和任务中心的界面。协调 Bot 可提出业务命令，但不获得无限权限。分派不是完成；提交证据文本不是自动验证。跨云持续运行需要预算、并发、重试与人工接管边界。

## 参考范围

分析固定在 DS-Bot d104d9ca18d69a35460f14e15dff4d553181433a，基于 README、设计文档和部分源码；没有运行 DS-Bot 或导入其代码。设计描述与已检查实现不可混为一谈。产品更新以感知、助手和任务闭环为主，多 Agent 不是核心用户模型。英文原分析保留每项原始来源链接。
