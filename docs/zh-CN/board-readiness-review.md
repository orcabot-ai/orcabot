# 维度就绪度评审

[English](../en/board-readiness-review.md) · 简体中文

## 如何评分

原评审从清晰度、可实现性、可验收性三个角度评估十个维度，各项满分 10 分。评分是当时的规划快照，不表示当前已完成程度；实现后的证据单独记录在 P1 与验证文档中。

## 需要补齐的契约

工作区需明确身份边界；Thread 需规定上下文选择和决策来源；协调需有租约代次、幂等与 unknown 策略；身份需独立可撤销凭证；执行需保持原身份；激活需去重、预算与失败处理；连接器需认证与重放；流程需版本、验收主体和证据约束；界面需待处理语义；运维需迁移、分页与一致性恢复。

## 已落实与后续

P1 已补租约、事务性执行意图、不可变文本证据、人工通过/返工、历史和命令行。自动唤醒、一般依赖图、独立 Agent 权限和自动验收仍不应按“可直接上线”计分。完整历史逐项分值与依据保存在对应英文评审表。
