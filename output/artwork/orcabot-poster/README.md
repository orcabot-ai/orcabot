# Orcabot AI poster

[简体中文](README.zh-CN.md)

A standalone landscape poster with a Gemini-generated blue filament field. The right side is kept quieter for the approved full-screen background and floating sign-in panel direction.

- `orcabot-poster.png`: full-resolution branded poster.
- `background.jpg`: clean background for later UI use.
- `preview.jpg`: lightweight preview.
- `prompt.txt` and `provenance.json`: generation and composition record.

The sign-in layout is not baked into the artwork.
